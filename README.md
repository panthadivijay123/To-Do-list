# To-Do List App

A simple To-Do List web application built using HTML, CSS, and JavaScript.

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, arrays, loops, functions, and LocalStorage.

## Features

- Add new tasks
- Prevent empty tasks
- Prevent duplicate tasks
- Delete tasks
- Mark tasks as completed
- Edit existing tasks
- Prevent empty edited tasks
- Prevent duplicate edited tasks
- Cancel editing
- Clear all tasks
- Display total task count
- Display completed task count
- Save tasks using LocalStorage
- Restore saved tasks after refreshing the page
- Error messages for invalid input
- Hover and focus effects
- Responsive container using CSS `max-width`

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
